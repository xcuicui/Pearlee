# Proposal: mood-curve-end2end-v1

## Background
写碎碎念已经能“收纳”日常，但目前缺少一个**可回看、可理解的情绪轨迹**：今天的心情如何、这一周的心情趋势如何。

我们希望把“心情曲线”**融合进首页周历**（而不是新增独立模块），用克制的点线趋势让用户轻轻看见最近 7 天的心情变化，并且可以点开某一天查看那天最后一条碎碎念的心情与摘要。

## Goals
- 发布碎碎念时：新增「今天的心情」4 选 1（emoji + 文案），并将 `mood_level(1~4)` 随发布写入。
- 数据层：Moment/碎碎念（entries）新增 `mood_level` 字段；聚合最近 7 天心情序列（同日取最后一条，且仅统计带 `mood_level` 的碎碎念）。
- 首页周历融合：在现有周历内绘制 7 天点线趋势（无轴/无数字），点击某一天（点位或日期格）弹出详情：日期 + emoji+文案 + 当日最后一条碎碎念摘要（最多两行）。

## Non-goals
- 不新增“关系温度”独立模块卡片。
- 不显示任何分数/评分/数字刻度（不 KPI 化）。
- 不绑定积分系统。
- 不引入新图表库。
- 不重构首页整体布局（关系标题/情绪卡片/FAB 不动）。

## Risks & Mitigations
- **周历变拥挤**：用极简点线（小点 + 细线、低饱和色），无轴无数字；详情放弹层解释。
- **理解成本**：弹层标题「这一天的心情」+ emoji+文案 + 摘要，帮助用户理解点位含义。
- **数据缺失**：历史碎碎念可能没有 `mood_level`；聚合时只统计有 mood 的记录，并对无 mood 日做空态提示。

## Rollback Plan
- Feature flag（或开关条件）关闭周历 `MoodTrendOverlay`，回到仅周历活跃标记。
- 发布页 `mood_level` 可从“必选”降级为“可选/默认值策略”（若需要回滚体验），但本 change 内会固定策略并在 spec 中写清。
