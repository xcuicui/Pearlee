# Design: points-help-page-v1

## Context
抽奖页现有“资产规则”文案较紧凑，适合在同区块增加一个低干扰入口；说明内容可通过独立静态页面承载，避免挤占主流程。

## Decisions
- 在抽奖页资产规则区使用小号链接“贝壳说明”，点击后 `navigateTo` 新页面。
- 说明页采用静态文本 + 分段标题（来源 / 怎么用 / 温馨提示）。
- 页面不做网络请求，文案全部来自 `utils/strings.js`。

## Trade-offs
- 采用静态文案可快速上线且稳定；后续若需运营可再升级为配置化。
- 将说明放在二级页而非抽奖页内展开，保持抽奖页主体简洁。

## Risks
- 文案若过于具体可能与未来规则不一致。
  - Mitigation: 本次文案保持泛化描述（例如“完成任务”等）。
