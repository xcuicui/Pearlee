# Spec: points-help-copy-centralized-v1

## Summary
将“贝壳说明”相关文案收敛到单一模块并复用到说明页、抽奖页入口、首页打卡提示与发布页提示；同时将说明页内容升级为更具体的来源/消耗/提示说明。

## Scope
- 新增统一文案模块，集中维护说明页标题、段落、链接文案与操作位短提示。
- 说明页使用统一文案模块渲染静态内容（无网络请求）。
- 首页“想念打卡”附近新增轻提示并可跳转说明页。
- 发布页新增轻提示并可跳转说明页。
- 抽奖页“贝壳说明”入口文案改为读取统一文案模块。

## Out of scope
- 不改奖励发放、打卡、抽奖、券包逻辑。
- 不改路由路径与页面层级结构。
